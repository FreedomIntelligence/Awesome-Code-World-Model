# Literature update · 2026-11-18

This search covered new arXiv submissions from October 30 through November 18, 2026. Titles, authors and submission dates were checked against the arXiv records. Placement and mechanism descriptions reflect the authors’ abstracts.

| Placement | Paper | Contribution |
|---|---|---|
| Programmatic dynamics | [Creating Hybrid Interactive Narrative Systems with LLM: From Formal Description to Evaluation](https://arxiv.org/abs/2611.02807) | Encodes narrative events as operations with explicit preconditions and effects. Three experience managers act on the same facts and goals, making their story trajectories comparable as plans. |
| Proxy worlds and generative rendering | [GameWM](https://arxiv.org/abs/2611.19247) | A game engine computes event timing, outcomes and camera state. A video model renders the interaction, allowing the same mechanic to take different visual forms. |
| Proxy worlds and generative rendering | [CoCode-World](https://arxiv.org/abs/2611.15602) | Renders two players’ views jointly from a shared programmable 3D proxy and RGB references. Synchronized GTA V observations test whether characters retain their appearance across viewpoints. |
| 3D world construction | [SceneAgent (portable game scenes)](https://arxiv.org/abs/2611.17821) | Stores the evolving game scene in a persistent SceneContext. Builder agents reuse layout skills across engines while adapters translate coordinates, bind assets and export scenes. |
| 3D world construction | [TelePhysica](https://arxiv.org/abs/2611.18078) | Reconstructs visual meshes and executable physical models from a photograph, checks equilibrium, then simulates interventions such as reversing an applied force. Simulated trajectories can also guide video synthesis. |
| Other · GUI | [WebHarbor](https://arxiv.org/abs/2611.03634) | Coding agents extend Dockerized replicas of real websites as new tasks arrive. Human contributors check visual fidelity and workflow behavior across 153 environments. |
| Evaluation · symbolic dynamics | [Evaluating LLM-Generated World Models for Neuro-Symbolic Reasoning](https://arxiv.org/abs/2611.14419) | Evaluates formal models generated as partially observable stochastic games on 44 scenarios. Mechanical checks, structural agreement and semantic judgments test different aspects of fidelity. |
| Evaluation · rendering | [WorldDraft](https://arxiv.org/abs/2611.16217) | Across 432 paired cases from 48 executable 4D world families, varies proxy detail and appearance cues while holding dynamics fixed. Scores motion and camera preservation separately from target appearance. |
| Evaluation · construction | [Frontier3DBench](https://arxiv.org/abs/2611.09017) | Evaluates coding agents on 145 object, scene and interactive-world tasks. Open-world tests distinguish working local mechanisms from activities requiring clearance and persistent state. |
| Evaluation · construction | [VibePrevisBench](https://arxiv.org/abs/2611.15789) | Tests executable Blender scenes on 242 briefs. Scene Check reruns code against hidden 4D facts, and Screen Check judges whether the verified facts are visible in the rendered preview. |
| Evaluation · construction | [OCTAVE](https://arxiv.org/abs/2611.17681) | Evaluates generated HTML5 games against 1,800 requirements across 180 tasks. Static source inspection scores specified features and deeper relationships among game systems. |
| Evaluation · video world models | [FlipTest](https://arxiv.org/abs/2611.19822) | Uses near-identical initial frames, matched controls and dense parameter sweeps to test whether video predictions change at the physical boundary where an outcome flips. |
